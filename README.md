> **Focus:** Network Security · Linux Security · Windows / Active Directory

## 📌 Overview

The **Secure Infrastructure Lab** is the first project in my cybersecurity portfolio.

The goal of this project is to build a small IT environment and progressively apply security concepts as I advance through my cybersecurity training.

Rather than treating networking, Linux, and Windows security as isolated topics, this project will bring them together into one documented infrastructure environment.

The lab will evolve alongside my **CHCSS + Linux** studies, with configurations, security controls, testing, and documentation added as the relevant concepts are learned and implemented.

---

## 🎯 Project Objectives

The project is designed to develop practical experience in:

- 🌐 Building and understanding network infrastructure
- 🐧 Configuring and securing Linux systems
- 🪟 Working with Windows and Active Directory environments
- 🔐 Applying system and network security controls
- 🔎 Identifying insecure configurations and potential weaknesses
- 🧪 Testing and validating security changes
- 📊 Comparing system state before and after hardening
- 📝 Creating clear technical documentation
- 💡 Analyzing results and documenting lessons learned

## 🔬 Methodology

For major security changes, I will aim to document the process using an evidence-based workflow:

**1️⃣ Understand → 2️⃣ Configure → 3️⃣ Test → 4️⃣ Analyze → 5️⃣ Improve → 6️⃣ Document**

Where appropriate, security controls will be documented using a **Before → Change → Validation → After** approach.

This makes it possible to demonstrate not only what was configured, but also **why the change was made and whether it worked as intended**.
